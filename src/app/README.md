### /src/app
- **`chat_loop.py`** - Main chat interaction loop, handles user input and model responses
- **`dial_loop.py`** - Dial queue loop: show lead, log outcome, advance
- **`analytics.py`** - Analytics screen: filter, load counts, show panel
- **`initializers.py`** - Initialization logic for model, RAG, and session components
- **`session.py`** - Session management, coordinates context, RAG, and model interaction
